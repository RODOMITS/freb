# Защита и эксплуатация Brainrot Freebie

Версия 1.7.0 усиливает защиту приложения от HTTP-перегрузки. Это не гарантия защиты от любой DDoS-атаки: фильтрация сетевого трафика должна работать на стороне Bothost/прокси.

## Что включено по умолчанию

- Проверка Telegram initData и серверные права администратора, секрет webhook.
- Тело JSON до 32 KiB, чтение по частям, общий срок загрузки 8 секунд. Сжатые входящие тела не принимаются.
- До 24 одновременных API-запросов, 8 отдельных запросов webhook и 64 запросов публичных ресурсов. При заполнении — 503 с Retry-After; Telegram сможет повторить уведомление.
- Ограничения по IP, сессии и пользователю, включая состояние, историю, каталог, платежи и создание резервных копий. Недействующая сессия не открывает данные.
- Ограничители памяти имеют фиксированный предел ключей и не сбрасывают всех пользователей при переполнении.
- Лимиты успешных операций и входов записываются в SQLite и переживают перезапуск. Повтор операции с прежним ключом не начисляет деньги повторно.
- Обычные чтения используют отдельные read-only соединения и не занимают блокировку записи. Денежные изменения выполняются в транзакции. SQLite synchronous=FULL сохраняет требования к сохранности платежей.
- Таймер выбирает по индексу только игры, которым пора завершиться. Их сроки сохраняются в базе и восстанавливаются после перезапуска.
- Большие JSON-ответы сжимаются. В таблице повторных запросов хранятся результаты, а не полные копии инвентаря, истории и всего состояния.
- CSP разрешает только собственные скрипты, официальный Telegram SDK и точные хеши встроенных скриптов. Добавлены ограничения браузерных возможностей и служебные заголовки.

## Настройки Bothost

Главный файл и команда запуска остаются прежними: main.py / python main.py. Один процесс, workers=1. Порт — PORT из панели, адрес 0.0.0.0. Базу не очищать.

Дополнительные настройки необязательны:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| API_CONCURRENCY | 24 | Одновременные API-запросы, от 1 до 128. Повышать только после измерений ресурсов. |
| REQUEST_BODY_TIMEOUT | 8 | Срок загрузки тела запроса, от 1 до 30 секунд. |
| FORWARDED_ALLOW_IPS | 127.0.0.1 | Доверенные адреса/CIDR внутреннего прокси. Получить у Bothost. Значение * запрещено. |
| BACKUP_DIRECTORY | каталог data/backups | Можно указать отдельный подключённый постоянный том для копий. Это не подключает облачное хранилище автоматически. |

Приложение не доверяет произвольному X-Forwarded-For. Если адрес прокси не указан правильно, в ограничениях по IP все пользователи за ним могут выглядеть как один клиент. Не исправлять это доверием ко всем адресам: запросить точный адрес/сеть у Bothost.

На прокси желательно также включить предел тела 32 KiB, лимиты соединений/запросов и таймауты загрузки. Не ставить проверку CAPTCHA перед /webhook: Telegram должен получать ответ напрямую, с проверкой секретного заголовка.

## Что остаётся сделать вне кода

- Уточнить у Bothost, какая фильтрация DDoS и HTTP-флуда действует для домена и тарифа.
- Хранить копии базы вне того же диска/сервера. Копии рядом с базой не защищают от потери диска.
- Включить двухэтапную защиту Telegram администраторов и GitHub, не делиться сессиями и токенами.
- При утечке перевыпустить токен бота, webhook secret или секрет ссылки автоматического обновления Bothost.
- Настроить наблюдение за 429/503, временем ответов, CPU/RAM и свободным диском.
- Провести согласованный нагрузочный тест на отдельном окружении. Этот PR не отправляет атакующий трафик на рабочий сайт.

Нельзя ставить деньги или давать права на основании данных браузера. Проверьте новые платежи, отмену депозита, заморозку, таймер игр и розыгрыша после развёртывания. Уже применённые блокировки пользователей сохраняются.

## Зависимости и отключённые поверхности

В закреплённой Starlette 0.46.2 есть известные риски разбора Range и multipart. Range-запросы отвергаются до StaticFiles/FileResponse, API и webhook принимают только ограниченный JSON; multipart не разбирается. Добавлены предел суммарного размера заголовков и проверка синтаксиса Host. Это закрывает используемые приложением входы для этих атак; отдельное обновление FastAPI/Starlette требует проверки совместимости.

Источники: [Range DoS](https://github.com/Kludex/starlette/security/advisories/GHSA-7f5h-v6xp-fcq8), [multipart DoS](https://github.com/Kludex/starlette/security/advisories/GHSA-2c2j-9gv5-cj73).
