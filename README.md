# Запуск только на Bothost

Структура репозитория обязательна: `main.py` находится в корне, Python-модули — в `backend/`, интерфейс — в `web/`, изображения — в `web/img/`. При загрузке сохраняйте папки. Из GitHub выбирайте этот репозиторий и главный файл `main.py`; передеплой обновляет код, а база остаётся в `/app/data`.

Проверка структуры и запуска из другой рабочей папки: `python -m unittest discover -s tests -v` после установки `requirements.txt`.

Загружай **Bothost.zip**, а не всю рабочую папку Freebie. Архив содержит только приложение: `main.py`, зависимости, настройки и две папки `backend` и `web`. Файлы внутри `web/img` — картинки персонажей, кейса и логотип. Это **один бот и один процесс Python**; отдельный хостинг сайта, Node.js, Docker и внешний API для первого запуска не нужны.

## В панели Bothost

1. Создай/открой своего Telegram-бота, выбери **Python** и загрузку проекта из архива. Загрузи `Bothost.zip`.
2. Главный файл: **`main.py`**. Если есть отдельные поля команд: установка `pip install -r requirements.txt`, запуск `python main.py`. В чистом архиве нет `package.json`, поэтому Bothost не перепутает проект с Node.js.
3. Включи **«Использовать домен»**, порт **8000**. Приложение читает `PORT` и слушает `0.0.0.0`. Скопируй HTTPS-адрес, показанный Bothost: собственный домен не обязателен. Автоматическую HTTP-обёртку не включай.
4. В переменных окружения поставь:

```text
BOT_TOKEN=токен_твоего_бота
PUBLIC_URL=https://твой-адрес.bothost.tech
PORT=8000
DATABASE_PATH=/app/data/freebie.sqlite3
PAYMENTS_ENABLED=false
```

Токен вводи в панели хостинга, не в переписке и не в ссылке браузера. Для твоего проекта можно использовать `https://bot-1782830182-5155-rodomits.bothost.tech`, **если именно этот адрес Bothost показывает текущему боту**.

5. Сделай деплой. Приложение само создаст секрет webhook в `data/.webhook-secret`, настроит `/webhook` и кнопку открытия Mini App в меню бота. При временной недоступности Telegram/DNS настройка повторится через 30 секунд. В логах должно появиться `Telegram webhook and menu configured`.
6. Открой `https://твой-адрес/health`: ожидается `{"ok":true}`. В Telegram напиши боту `/start` и нажми «Открыть». В обычном браузере игровые операции недоступны.
7. Добавь бота администратором канала `-1003739017107`. Владельцу `7613236278` нужно написать боту `/start`, иначе бот не сможет присылать ему уведомления о заявках. Админы `7613236278` и `1821268346`, контакт `@DarkMonstep` уже заданы по умолчанию.

Не запускай рядом старого бота на polling с тем же токеном: доставка обновлений теперь идёт в webhook этого приложения.

## База и обновления

Bothost документирует папку `data` как место для базы, исключённое из синхронизации исходников. На конкретном тарифе проверь в панели/поддержке сохранение этой папки при пересоздании контейнера. Цена «199 ₽» сама по себе не подтверждает наличие всех функций тарифа. **Не удаляй `data` и не загружай туда пустую базу при обновлениях.**

Автоматически создаются ежедневные SQLite-копии, сохраняются последние семь файлов. В веб-админке есть «Скачать резервную копию». Храни копии и вне Bothost: файл в том же хранилище не защищает от потери всего аккаунта/диска. Резервная копия содержит данные пользователей и секретные seeds — не выкладывай её публично.

## Что подготовлено к денежным операциям

- Серверные права, баланс в сотых BStars, транзакции, уникальные предметы и защита повторных запросов.
- Максимальная выплата за игру **10 000 BStars**. В ракетке ставка не больше **100 BStars**, чтобы даже ×100 укладывался в этот предел. Общая ставка раунда — до 1000 BStars.
- Мины заранее показывают шаг автоматического завершения. Предел определяется до выбора случайного поля; выплата не обрезается после выигрыша, математический возврат остаётся прежним.
- Максимальный активный риск — 100 000 BStars. Это максимум потенциальных выплат незавершённых игр, а не гарантия наличия денег или прибыльности проекта.
- Общий бюджет ежедневных/подписных кейсов и промокодов — **1000 BStars в сутки** по стоимости каталога. После исчерпания новые бонусы отклоняются до следующего дня; шансы не подменяются.
- Вывод — до 10 000 BStars на заявку и пользователя в сутки; только четыре согласованных персонажа. После оплаты Stars действует **21 день ограничения вывода**, показанный перед покупкой. Игры доступны. Этот срок снижает риск немедленной выдачи, но не исключает последующие споры и chargeback.
- Возврат Stars через веб-админку требует отдельного подтверждения. Только ответ Telegram/проверенное уведомление подтверждает возврат. Потраченные BStars становятся задолженностью; новые игры и вывод блокируются. Неопределённый результат API сохраняется для проверки, успех не выдумывается.
- Приостановка новых ставок в админке оставляет возможность завершить уже оплаченные игры.

Лимиты находятся в одном файле **`limits.json`**. Они предварительные, их можно изменить и передеплоить. Уже принятые игры сохраняют записанные параметры. Наличие запаса предметов и RTP не гарантирует прибыль.

## Включение Stars

Пока включён режим без покупок. До включения:

1. Опубликуй свои условия покупки/вывода и политику приватности; укажи `TERMS_URL` и `PRIVACY_URL` как HTTPS-ссылки. В условиях должны быть курс 1 Star = 1,5 BStars, лимиты, срок ограничения вывода и процедура возвратов. Убедись в допустимости конкретной игровой модели по правилам платформы и применимым требованиям.
2. Проверь тестовый сценарий Telegram Stars: invoice → pre-checkout → успешная оплата → одно начисление → возврат → одно списание. Локальные тесты используют подмену Telegram; они не заменяют эту проверку в платформе.
3. Проверь обработку депозитов, выводов, ролей админов, перезапуск с сохранением БД и загрузку резервной копии.
4. Только после проверки поставь `PAYMENTS_ENABLED=true` и передеплой. При отсутствующих токене, webhook secret, условиях или политике приватности покупки останутся выключены.

Реальных платежей и деплоя на твой аккаунт в этой работе не выполнялось. Споры, возвраты после уже завершённого трейда, работоспособность выдачи и юридические условия остаются ответственностью владельца. Telegram-уведомления об известных возвратах обрабатываются; банковский chargeback может потребовать отдельной сверки журнала Stars владельцем.

Официальные инструкции: [главный файл](https://bothost.ru/docs/main-file-entrypoint), [домены и порты](https://bothost.ru/docs/domains-and-ports), [хранение базы](https://bothost.ru/docs/database-storage), [Telegram Stars](https://core.telegram.org/bots/payments-stars).

## Игровой каталог

Предметы, цены и составы платных кейсов редактируются только в `backend/catalog.json`. Бесплатные кейсы формируются сервером в `backend/service.py`. Клиент получает каталог, правила слотов и параметры расчётов через `/api/catalog` после авторизации Telegram. `web/config.js` содержит только пустые контейнеры и проверку ответа сервера; дублировать в нём каталог не нужно. Без доступного API или Telegram-авторизации клиент не запускает локальные игры. Данные, необходимые для отображения, доступны пользователю после получения ответа API; результаты и начисления определяет сервер.
